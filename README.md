# Flamengo Stats

Painel de estatísticas do Flamengo no Brasileirão, feito com Python.

## O que mostra

- Pontos, aproveitamento e saldo de gols
- Comparativo entre jogos em casa e fora
- Vitórias, empates e derrotas por local
- Evolução de pontos rodada a rodada
- Filtro por local do jogo

## Tecnologias

- Python
- pandas (cálculos)
- plotly (gráficos)
- Streamlit (site)

## Como rodar

    pip install -r requirements.txt
    streamlit run app.py
